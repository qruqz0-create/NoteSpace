 NoteSpace

 Описание проекта
NoteSpace - Android-приложение для создания и хранения личных заметок. Приложение разработано на Kotlin с использованием XML-разметки.

 Основные возможности
- Создание новых заметок.
- Сохранение заметок после перезапуска приложения.
- Поиск заметок по тексту.
- Просмотр списка заметок.
- Возврат на главный экран.
- Проверка заполнения названия заметки.
- Запись событий приложения в файл `logs.txt`.

Используемые технологии
- Kotlin
- Android SDK
- XML
- SharedPreferences для хранения заметок
- JSON для сохранения списка заметок
- GitHub для хранения исходного кода

 Структура проекта
- `MainActivity.kt` - главный экран приложения.
- `NotesActivity.kt` - список заметок и поиск.
- `DetailActivity.kt` - создание заметки.
- `NoteStorage.kt` - сохранение и загрузка заметок.
- `LogHelper.kt` - запись событий в лог-файл.
- `res/layout/` - XML-разметка экранов.
- `res/values/` - строки, цвета и размеры.

## Запуск проекта
1. Склонировать репозиторий NoteSpace.
2. Открыть проект в Android Studio.
3. Дождаться завершения синхронизации Gradle.
4. Запустить приложение на эмуляторе или Android-устройстве.
